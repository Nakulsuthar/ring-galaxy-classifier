# ring-galaxy-classifier

Fine-tuning [Zoobot](https://github.com/mwalmsley/zoobot) to find ring galaxies in
Euclid imaging, as part of an MPhys project at Lancaster University (supervisor: Prof. Brooke Simmons).

Rings are among the most common features in disc galaxies, but the Euclid Q1 and DR1 morphology
catalogues contain no ring classifications. This project trains a ring classifier on top of the
Euclid Zoobot encoder, applies it to Euclid Q1, and aims to build a ring catalogue from DR1.
